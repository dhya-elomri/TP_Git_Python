TP 1 - MON ASSISTANT DE Révision
1.Présentation:
-Nom du projet :MON ASSISTANT DE Révision
-Objectifs:
ce programme Python permet à l'utilisateur de préparer une séance de révsion en saisissant quelqueqs informations.
lefichier main.py contient le programme principal.il affiche un message de bienvenue et demande les informations nécessaires à l'utilisateur.
2.évolution du programme(V1 à V4):
V1-Message de Bienvenue:
création du programme avec un premier message de bienvenue affiché localement.
V2-Ajout du Prénom:
Modification du programme pour demander la prénom de l'utilisateur,Puis premier envoi du projet sur GitHub avec git push
V3-Ajout de la maniére:
Ajout d'une question permettant à l'utilisateur de choisir la matiére à réviser.Récupération des modifications avec git pull
V4-Ajout de la durée:
Ajout d'une question permettant de saisir la durée de révision en minutes.Envoi de la nouvelle version sur GitHub avec git push.
3.Comment exécuter le programme ?
Outils nécessaires
*Un ordinateur Windows.
*Python installé.
*Visual Studio Code.
*Le fichier main.py.
Étapes d’exécution
1.Ouvrir le dossier TP_Git_Python dans Visual Studio Code.
2.Cliquer sur le fichier main.py.
3.Cliquer sur Run Python File en haut à droite.
4.le terminal intégré s’ouvre automatiquement.
5.Saisir les informations demandées :
    * Le prénom.
    * La matière à réviser.
    * La durée de révision en minutes.
6.Valider chaque réponse avec la touche Entrée.
4.Commandes Git utilisées:
Commande | 	Rôle
git init  |	Initialiser un dépôt Git.
git add	Ajouter les fichiers à préparer pour l’enregistrement.
git commit |	Enregistrer les modifications localement.
git push | 	Envoyer les modifications vers GitHub.
git pull  |  Récupérer les dernières modifications depuis GitHub.
